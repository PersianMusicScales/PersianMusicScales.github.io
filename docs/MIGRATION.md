# Original website and Wiki audit

Reviewed 23 November 2026. The published navigation exposed 11 Google Sites pages. Each was retrieved individually. The Wiki landing page and all 18 linked English/Persian topic documents were retrieved directly, including raw Markdown. The Wiki is a documentation layer maintained with the app. The new site can point each language to the corresponding topic.

## Google Sites migration map

Paths below are relative to https://sites.google.com/view/persianmusicscales/. Target names identify the educational destination in either language.

## Wiki structure and authority

Use https://github.com/PersianMusicScales/Persian-Music-Scales-App/wiki followed by the route in this table. Each page has a counterpart labeled EN or FA. The English pages use Markdown, and Persian pages also use explicitly directed HTML to handle RTL.

| Suffix after EN- or FA- | Authoritative subject and use |
|---|---|
| Overview | Audience, purpose and scope. Link from About or Tools. |
| Getting-Started | Playback, selection, transposition and notation controls. Link from the app introduction. |
| Music-Theory | Dastgah, avaz, radif, gusheh, koron/sori and tonal roles. Use for deeper bilingual reading. |
| Scale-Reference | Published educational arrays for eight entries including the Mahur/Rast-Panjgah pair. Natural Minor is an additional comparison mode outside this Persian reference list. Keep data with the app. |
| Audio-Analysis | Microphone/file workflow, ranked hypotheses and recording conditions. Link from listening guidance. |
| Scientific-Methodology | Angle mapping, transposition, theoretical spellings and model limits. Explain the principle once and link here for details. |
| Technical-Guide | Installation, data, development and browser support. The central website does not require visitors to install the app. |
| FAQ | Troubleshooting stays with the relevant software version. |
| Citation-and-Licensing | CITATION.cff, original material, third-party terms and permission contacts. Link to the actual license as the authority. |

Cross-links verified in the Wiki include the [model data](https://persianmusicscales.github.io/Persian-Music-Scales-App/data/persian-scales.json), [methodology](https://persianmusicscales.github.io/Persian-Music-Scales-App/reference/methodology.html), [audio methods](https://persianmusicscales.github.io/Persian-Music-Scales-App/reference/audio-analysis.html) and [source provenance](https://persianmusicscales.github.io/Persian-Music-Scales-App/reference/sources.html). For paper citations or independent research use, distinguish the model author from scholarship on repertoire and performance.

## Transition

After the owner authorizes publication and verifies the public URL, add a bilingual notice and link to the old homepage and the most visited original pages. Keep existing URLs, reference materials and audio in their original locations. Test the incoming and outgoing links before announcing the move. No automatic Google Sites redirect or destructive migration is assumed.
